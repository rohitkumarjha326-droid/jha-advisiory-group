Jha Advisory Group — Website (Single Page)

How to preview locally (Windows/macOS/Linux):
1) Download this folder and unzip it.
2) Open the file named index.html in your browser (double-click).
3) Replace assets/logo.png with your real logo if available (use the same file name).

How to put on your domain (two quick options):

Option A — Upload to a cPanel hosting:
1) Buy hosting + enable SSL (HTTPS).
2) Open cPanel > File Manager > public_html/
3) Upload all files from this folder so that index.html sits inside public_html.
4) Visit: https://your-domain/
5) If you use a subdomain (like site.your-domain), upload into that subdomain's document root.

Option B — Free static hosting with Netlify:
1) Create a free Netlify account.
2) Drag and drop this folder into Netlify or connect a GitHub repo with these files.
3) Netlify will give you a live URL. Add your custom domain in Netlify's Domain settings and update DNS.

SEO tips:
- Keep the title and description in <head> updated.
- Add Google Analytics (GA4) if you need traffic stats.
- Maintain consistent NAP (Name, Address, Phone) across the web.

Edits:
- This is a single-file site. You can modify content inside index.html with any text editor.
